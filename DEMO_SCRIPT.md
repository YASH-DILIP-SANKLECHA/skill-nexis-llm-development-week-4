# 2–3 Minute Demo Script

**0:00–0:20:** Explain that the assistant retrieves evidence from course documents and cites document/page references.

**0:20–0:45:** Upload all three PDFs from `sample_documents`, click **Index documents**, and show indexed status.

**0:45–1:15:** Ask “What is overfitting?” Show answer and source reference.

**1:15–1:40:** Ask “How do chunking and cosine similarity work together in retrieval?” Inspect retrieved passages.

**1:40–2:00:** Ask “What exact accuracy percentage did the sample classifier achieve?” Demonstrate abstention when unsupported.

**2:00–2:20:** Select `02_retrieval_and_rag.pdf`, generate its summary, and generate five practice questions.

**2:20–2:45:** Show the 20-question CSV and run `python evaluate.py`. Open results/report and explain that correctness/source accuracy are manually reviewed.
